# Patent Claim Completeness Checker

A single-page tool that checks whether every compound disclosed by scientists appears in a patent application's claims section, and flags any that are missing before submission.

- Dashboard with review statistics, a New Review screen, a result view with a completeness score, and a searchable Review Library
- Runs entirely in the browser. Reviews are saved to `localStorage`; there is no backend or login.
- Ships with fictional sample data (e.g. `Compound-A114`). It has no connection to real patent filings or proprietary data.

Open `index.html` in a browser, or visit the GitHub Pages site.
